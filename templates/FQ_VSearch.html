Variable Sites

The Find Variable Sites tool generates Excel (.xlsx) spreadsheet with the counts of all amino acid combinations for the variable sites.

  • Reference Sequence (.fasta)

    This is a fasta file either in the (.fa) or (.fasta) format. The fasta file should be the sequencing amplicon reference sequence. The reference sequence must include variable sites, which are marked using any non-standard codon, such as NNN, NNK, or XXX.

  • Data Sequence (.fastq)

    This is the fastq file containing sequencing data from a sequenced amplicon. The library should be derived from the reference sequence (provided above). The tool will use this file to compare against the reference to identify variable sites for both the forward and reverse complement sequences.

  • Output File Name

    Enter the desired name for the output file. The file will be created in the Excel format (.xlsx).

  • Number of Matching Nucleotides (5' End)

    Specifies how many nucleotides, starting from the 5' end of variable site need to match the reference sequence. Any site that does not match the sequence will be discarded.

  • Number of Matching Nucleotides (3' End)

    Specifies how many nucleotides, starting from the 3' end of variable site need to match the reference sequence. Any site that does not match the sequence will be discarded.

  • Phred Score Threshold

    Minimum Phred score required for each nucleotide within the matching 5' and 3' regions. If any nucleotide has a Phred score below this threshold, the corresponding sequence will be discarded as unreliable. If the optional barcode option is used, the barcode will also use this Phred score value.

  • Number of Variable Sites

    This field specifies the expected number of variable sites in the reference sequence. If the number of variable sites detected does not match this expectation, the program will return an error, indicating a mismatch.

  • Barcode Check (Optional)

    For multiplexing include a unique sequence barcode. The program will filter out any sequences that do not contain the specified barcode. The data sequence file can be re-run with multiple barcodes.
