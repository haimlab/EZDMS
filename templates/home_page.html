EZ-DMS

Software Package for Deep Mutational Scanning of Virus Proteins.

Variable Sites


Process FASTQ files to generate a Excel file for the counts of amino acid combinations.

Amino Acid Preference


Determine amino acid preferences between an input and a output data set relative to wildtype.

Build Primer


The tool creates the 4 primers needed to create a plasmid library from a reference sequence in a text file (txt).
