Amino Acid Preference

The Find Amino Acid Preference generates a excel file (.xlsx) for amino acid preferences between two data sets, commonly an input and output sequence. Preferences are normalized against the wildtype sequences

  • Reference Sequence (.fasta)

    This is a fasta file either in the (.fa) or (.fasta) format. The fasta file should be the sequencing amplicon reference sequence. The reference sequence must include variable sites, which are marked using any non-standard codon, such as NNN, NNK, or XXX.

  • Data Sequence 1(.fastq)

    This is the input fastq file containing sequencing data from a sequenced amplicon. The library should be derived from the reference sequence (provided above). This file is what the second, data sequence 2 file, is compared too.

  • Data Sequence 2(.fastq)

    Requires the same format as Data Sequence 1. The amino acid preference for Data Sequence 2 is calculated relative to Data Sequence 1.

  • Number of Matching Nucleotides (5' End)

    Specifies how many nucleotides, starting from the 5' end of variable site need to match the reference sequence. Any site that does not match the sequence will be discarded.

  • Number of Matching Nucleotides (3' End)

    Specifies how many nucleotides, starting from the 3' end of variable site need to match the reference sequence. Any site that does not match the sequence will be discarded.

  • Phred Score Threshold

    Minimum Phred score required for each nucleotide within the matching 5' and 3' regions. If any nucleotide has a Phred score below this threshold, the corresponding sequence will be discarded as unreliable. If the optional barcode option is used, the barcode will also use this Phred score value.

  • Output File Name

    Enter the desired name for the output file. The file will be created in the Excel comma separated value file format (.csv).

  • Wild Type Amino Acid Site 1

    Enter the wildtype amino acid present at first variable site.

  • Wild Type Amino Acid Site 2 (Optional)

    Enter the wildtype amino acid present at second variable site, if applicable. Do not change if only 1 variable site is present.
